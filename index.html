Cluster & Failover

O cluster Proxmox com HA Manager garante que, se um nó falhar, todas as VMs reiniciam automaticamente noutro nó em menos de 3 minutos. O Ceph replica os dados em 3 discos SSD simultaneamente.

Dificuldades & Soluções

Integração LDAP Nextcloud ↔ Active Directory
A configuração correta do Base DN, credenciais de serviço e filtros de utilizadores exigiu testes incrementais. Pequenos erros na sintaxe impediam completamente a autenticação.
pfSense como VM dentro do cluster (dependência circular)
Se a VM pfSense fosse o único gateway do Proxmox, a sua falha bloquearia o acesso ao hypervisor. Solução: dupla conectividade — rede interna via pfSense para o lab e acesso direto à rede física para administração.
pve-exporter com montagem de volumes Docker
O pve-exporter falhava ao tentar montar o ficheiro de configuração como volume. Solução: substituição por variáveis de ambiente no Docker Compose.
